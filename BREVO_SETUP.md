# PROACT System - SMTP and Email Setup

When a **Super Admin** adds a new user, or when events are created, the system sends notifications and account credentials via email. This document explains how to set up the email notifications.

---

## Configuration Options

There are two ways to configure the SMTP email provider:
1. **Settings Dashboard (Recommended):** Directly through the Admin Settings UI. This configures settings in the PostgreSQL `settings` database table.
2. **Environment Variables (Fallback):** Hardcoding the fallback values in the `backend/.env` file.

---

## Option 1: Admin Settings Dashboard (Recommended)

As a Super Admin, you can configure SMTP settings dynamically directly inside the application:

1. Log in to the PROACT Dashboard using your Super Admin account.
2. Navigate to **Settings** -> **SMTP Configuration**.
3. Fill in the following details:
   - **Provider:** e.g., `Outlook`, `Brevo`, `Gmail`, or `Custom`.
   - **Sender Name:** The display name for outgoing emails (e.g. `DOST Region I DRRMO`).
   - **Sender Email:** The verified sender email address.
   - **Host:** The SMTP server address (e.g. `smtp.office365.com` for Outlook, `smtp-relay.brevo.com` for Brevo).
   - **Port:** Usually `587` (TLS) or `465` (SSL).
   - **Username:** The login email address for your SMTP service.
   - **Password:** The password or App Password generated by your SMTP provider.
4. Save the configuration. The details will be encrypted and stored in the database.

---

## Option 2: Environment Variables (`backend/.env` Fallback)

If database configurations are empty, the backend falls back to using the environment variables defined in [backend/.env](file:///C:/Users/TUF/OneDrive/Desktop/DOST/PROACT/backend/.env).

Open your `backend/.env` file and append/edit the following keys:

```env
OUTLOOK_EMAIL=your_sender_account@outlook.com
OUTLOOK_PASSWORD=your_app_password
OUTLOOK_SENDER_NAME="DOST Region I DRRMO"
CLIENT_URL=https://proact.dost1.ph
```

> **Important:** Always use a **Google App Password** or an **Outlook App Password** instead of your primary account password if your email address uses two-factor authentication (2FA).

---

## Verification & Troubleshooting

If emails are not arriving:
1. **Check Logs:** Inspect the backend docker logs:
   ```bash
   docker logs proact_backend --tail 50 -f
   ```
2. **Verify Sender Address:** Most SMTP providers (including Gmail, Outlook, and Brevo) will reject outgoing mail if the `Sender Email` is not verified or does not match the authenticated account (`Username`).
3. **App Password Requirement:** If using Gmail/Outlook with 2FA, ensure you have generated an **App Password** from your account security dashboard.
4. **Port Configuration:**
   * Port `587` usually requires secure transport configurations.
   * Verify with your network administrator that outgoing SMTP traffic is not blocked on the host server.
